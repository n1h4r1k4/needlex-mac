<!-- title: NeedleX 0.1.1 — Updates Built In -->
**NeedleX now updates itself.** It looks for new releases and offers them in its menu-bar menu, so
this is the last version you download by hand. This release also fixes two island bugs.

One download works on **Apple silicon and Intel Macs** running **macOS 13 Ventura or later**.

## ⬇ Download

| File | What it is |
| --- | --- |
| **NeedleX-0.1.1.dmg** | Recommended. Open it and drag NeedleX into Applications |
| NeedleX-0.1.1.zip | The same app as a zip |
| NeedleX-0.1.1.app.tar.gz, latest.json | Used by the in-app updater; you don't need them |
| SHA256SUMS.txt | Checksums to verify the downloads (`shasum -a 256 -c SHA256SUMS.txt`) |

## 🔄 Coming from 0.1.0

0.1.0 can't update itself, so update by hand this one time:

1. Quit NeedleX from its menu-bar icon (**Quit NeedleX**).
2. Download **NeedleX-0.1.1.dmg**, open it and drag **NeedleX** into **Applications**. Choose
   **Replace** when asked.
3. Open NeedleX. Because it isn't notarized, macOS asks you to confirm it once (**System Settings →
   Privacy & Security → Open Anyway**), and it may ask for NeedleX's permissions again, such as
   controlling Spotify.

From now on, when there is a new version the menu shows **⬆︎ Update to NeedleX … and Restart** at
the top. **Check for Updates…** at the bottom of the menu looks right away.

## ✨ New

- **Updates built in.** NeedleX looks for a new release half a minute after it starts and then every
  six hours. Every update is signed, and the signature is checked before it is installed.
- **Lock screen clock styles:** System (rounded), Serif, Thin or Monospace (*Desktop wallpaper →
  Lock screen clock*).
- **‹ › arrows** on the sides of the open island to step between Player, Weather and Calendar.

## 🛠 Fixed

- A hard-edged square showed behind the island's rounded bottom corners a few seconds after it
  opened, most visible with the beat glow over a light window.
- After a while the notch could go missing next to some apps (their full-screen Spaces) until
  NeedleX restarted. It now puts itself back on every Space.

## 🔐 Privacy

The update check downloads `latest.json` from this project's latest GitHub release. Nothing about
you or your music is sent. See the
[README](https://github.com/n1h4r1k4/needlex-mac#permissions-and-privacy) for everything NeedleX
contacts.
